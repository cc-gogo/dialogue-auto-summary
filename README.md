# 对话自动总结 · Dialogue Auto Summary

> 给你的 AI 编程助手装一个自动总结功能：它会在**上下文压缩前**和**退出会话时**，把你和 AI 的对话自动写成一份中文 Markdown 笔记。

你花几十个小时和 AI 磨出来的方案、踩过的坑、定下的取舍，目前默认存在一个你不知道的文件夹里，连哪个文件你都找不到。同时冗余了几百兆的文件，你从来没有做过总结和凝练.这个项目就是来解决这件事的。

---

## 为什么需要它

拿 Claude Code 举例，原始记录存在 `~/.claude/projects/` 下，一条对话一个 `.jsonl` 文件。问题是：

| 问题 | 说明 |
|---|---|
| **会消失** | `cleanupPeriodDays` 默认 30 天，到时间自动删除 |
| **认不出** | 文件名是一串 UUID，只能一个个点开看 |
| **没提炼** | 全量原文，充满试错和重复，你不会去读 |
| **不在你手上** | 藏在 C 盘深处，没有备份，换电脑就没了 |

而最关键的窗口期是**上下文压缩**：AI 要把前半段对话丢弃、只留一个摘要。丢掉的那些——尤其是「当初为什么这么选」——再也回不来了。

这个功能就挂在这个时刻之前，**在你不知道的时候替你存档**。

---

## 装的到底是什么

三个触发点：

| 触发时机 | 说明 |
|---|---|
| **上下文满、自动压缩前** | 唯一的抢救窗口，AI 忘记之前先存一份 |
| **手动 `/compact` 前** | 你主动压缩，同样先存 |
| **退出会话时** | 关窗口、`/exit`、`/clear` 都算 |

触发时只做一件事：后台起一个进程，**1 秒内返回**，不卡你的操作。真正的总结在后台跑 20~90 秒。

产出长这样：

```
你的总结目录/
├── INDEX.md                    # 所有对话一行一条，扫一眼知道聊过什么
└── 2026-10-30_项目名_主题_8位ID.md
```

每份文件固定包含：**做了什么 · 结论 · 关键决策及理由 · 关键词 · 整体概览**。而且是**增量写入**——同一个对话续写同一份文件，不会每次生成新的。

## 可选：删对话时，摘要也一起删

总结会一直累积。如果你希望「删掉某个对话，对应的 `.md` 也一起消失」，可以打开这个开关：

```json
{ "deleteWithTranscript": true }
```

工作原理很轻：每次打开 Claude Code 时（`SessionStart`），后台扫一遍所有摘要，原始 `.jsonl` 已经不存在的就清掉对应的 `.md`、状态文件和索引行。

三道保护，防止误删：

- 只删**状态文件里登记过**、且正文含完整会话 ID 的 `.md` —— 总结目录里你手写的笔记不会被碰
- **扫描失败就整体放弃** —— 原始记录目录读不到、或一条 jsonl 都扫不到，直接不清理
- 默认**关闭** —— 不写这个字段就是 `false`，行为和以前完全一样

手动执行（先预览，再加 `--yes` 真删）：

```bash
node ~/.claude/hooks/summarize.js --sweep
node ~/.claude/hooks/summarize.js --sweep --yes
```

> 注意：`cleanupPeriodDays` 默认 30 天，到期时 Claude Code 也会自动删掉原始 `.jsonl`。这时摘要同样会被当成孤儿清掉。想长期保留就把它设成 3650（指南里已经这么做了）；只保留摘要、不要清掉的话，把这个开关保持关闭。

## 怎么用

**你不需要看懂技术细节。把下面这份指南整份发给你的 AI 就行。**

| 智能体 | 指南 |
|---|---|
| **Claude Code** | [`claude-code/Claude_Code_对话自动总结配置指南.md`](claude-code/Claude_Code_对话自动总结配置指南.md) |
| **Codex** | [`codex/Codex对话自动总结_跨电脑配置指南.md`](codex/Codex对话自动总结_跨电脑配置指南.md) |

具体做法：

1. 打开你平时用的 AI（Claude Code / Codex，或任何能读写本地文件的助手）
2. 把对应那份 `.md` 文件发过去
3. 说一句「按这个装」
4. 它会先问你：**总结文件想保存在哪个文件夹？** 回答之后它才会继续
5. 装完它会自己跑一遍测试，把结果告诉你

指南是**自包含**的：脚本代码、配置模板、验证步骤、踩坑清单都在里面，不需要额外下载任何东西。

## 常见问题

**Q：需要花钱吗？**
总结是在你本机调用你已有的模型，会产生少量 token 消耗。默认用便宜的小模型（如 haiku），每次总结通常几分钱以内。

**Q：会不会影响我正常使用？**
不会。触发时只派发一个后台进程就立刻返回，总结在你继续工作时于后台完成。

**Q：能自己指定保存位置吗？**
可以，安装时就会问你。之后想改，改配置里的一行路径即可，不用动代码。

**Q：和 AI 聊天里那些私人内容怎么办？**
总结只存到你指定的本地目录，不上传任何地方。原始 `.jsonl` 也不会被修改。

**Q：装完怎么手动补一份？**
Claude Code 装了 `/summary` 命令，随时可以手动触发。
